# AI Tool Approval Request

Front-door form for requesting a new AI tool, model, or vendor. Feeds the
intake/IBR process and routes to the buy / build / don't decision.

| Field | Detail |
|-------|--------|
| Request ID | REQ-AI-____ |
| Requester / department | |
| Date | |
| Priority | standard / expedited |

## 1. What & why

- [ ] Tool / vendor / product name and URL
- [ ] Problem it solves (current situation, pain)
- [ ] Proposed solution and how it will be used

## 2. Benefit hypothesis

- [ ] Value driver(s) and KPI(s) (revenue, cost, complexity reduction, customer satisfaction)
- [ ] Sized impact and the assumption behind it
- [ ] Which OKR / business goal this serves

## 3. Feasibility & scope

- [ ] Build vs buy (and why)
- [ ] One-time cost, recurring cost, FTE/effort
- [ ] IT integration depth (none / light / multi-team)
- [ ] Cross-department involvement?

## 4. Risk pre-screen

- [ ] Personal data processed? categories & data subjects
- [ ] Preliminary AI Act class (minimal / limited / high / prohibited signal)
- [ ] Automation with legal/significant effect (GDPR Art. 22)?
- [ ] External model / third-party data transfer?

## 5. Decision & routing

- [ ] smart.AI evaluation (feasibility + dependencies)
- [ ] DP classification (survivors only) + InfoSec in parallel
- [ ] Route: buy (Procurement) / build (smart.AI or IT) / don't
- [ ] Escalate to Executive Board? (high-risk, large complexity, cross-department)

**Outcome + assignee + date.** Link the IBR/business-requirement ticket here.
