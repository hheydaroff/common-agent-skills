# AI Acceptable Use Policy (Employee)

Short, plain-language rules for everyone using AI tools. Reference the full
org AI policy (see `ki-richtlinie-template.md`) for the formal obligations.

## 1. Scope

Applies to all employees, contractors, and anyone using company AI tools or
company data with any AI tool.

## 2. Golden rules

1. **Authorise first** — use only tools on the approved list; request new tools via `tool-approval-request.md`.
2. **Never put confidential or personal data into a public/unapproved model** (no customer data, secrets, credentials, unreleased financials into ChatGPT & co. unless that tool is explicitly approved for it).
4. **Verify before you rely** — AI output can be wrong or biased; you are responsible for decisions based on it.
5. **Label AI-generated content** when it will be used externally.
6. **Respect others' IP** — don't prompt for, or publish, third-party copyrighted material.
7. **Disclose AI interaction** to people when required (chatbots, automated systems).

| Level | Can it go into AI? |
|-------|--------------------|
| Public | yes, any tool |
| Internal | approved internal/enterprise tools only |
| Confidential | approved tools with contractual protections only |
| Secret / personal data | only with DP sign-off + DPIA |

## 5. Accountability

Violations are handled as policy breaches (up to disciplinary action). Report
suspected misuse or shadow-AI findings to the AI Officer.
