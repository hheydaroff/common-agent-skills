# High-Risk Compliance Checklist

Use after classifying a system as high-risk. Split by role.

## Provider (Anbieter) — Art. 16–22

**Requirements (Art. 9–15):**
- [ ] Risk-management system established, documented, maintained (Art. 9)
- [ ] Data governance: relevant, representative, error-free data; bias detection & mitigation (Art. 10)
- [ ] Technical documentation, kept current (Art. 11)
- [ ] Automatic record-keeping / logging for traceability (Art. 12)
- [ ] Instructions for use + transparency to deployers (Art. 13)
- [ ] Human-oversight mechanisms designed in (Art. 14)
- [ ] Accuracy, robustness, cybersecurity (Art. 15)

**Obligations (Art. 16–22):**
- [ ] Name/address on system, packaging or docs (Art. 16)
- [ ] Quality-management system (Art. 17)
- [ ] Keep documentation 10 years (Art. 18)
- [ ] Keep logs ≥ 6 months (Art. 19)
- [ ] Corrective action + inform authorities on non-conformity (Art. 20)
- [ ] Cooperate on "begründete Anfragen" (Art. 21)
- [ ] Authorised representative if outside EU (Art. 22)

**Conformity & registration (Art. 40–49):**
- [ ] Conformity assessment (internal / notified body; Annex VII mandatory if standards missing or Annex III No. 1)
- [ ] EU declaration of conformity (Art. 47)
- [ ] CE marking, incl. notified-body number if applicable (Art. 48)
- [ ] Register in EU database *before* market entry (Art. 49)
- [ ] Post-market monitoring (Art. 72) + serious-incident reporting (Art. 73)

## Deployer (Betreiber) — Art. 26

- [ ] Oversight only by trained, competent staff (Abs. 2)
- [ ] Use only suitable, representative input data (Abs. 4)
- [ ] Monitor per instructions; inform provider/authority of risks (Abs. 5)
- [ ] Keep logs ≥ 6 months (Abs. 6)
- [ ] Inform worker representatives & affected employees **before** deployment (Abs. 7)
- [ ] Public body → register in EU database (Abs. 8)
- [ ] DSFA where required (Abs. 9 + GDPR Art. 35)
- [ ] Remote biometrics: strict rules + judicial approval (Abs. 10)
- [ ] Inform affected persons a high-risk system is used (Abs. 11)
- [ ] Cooperate with authorities (Abs. 12)

## Fundamental-rights impact assessment (Art. 27) — where applicable

- [ ] Public body / private body providing public services? (or credit scoring / emergency triage?)
- [ ] Conducted before first use?
- [ ] Contents: purpose, duration, affected categories, harm risks, human-oversight measures, mitigation?
- [ ] Stakeholder involvement considered?
- [ ] Result reported to market-surveillance authority?
