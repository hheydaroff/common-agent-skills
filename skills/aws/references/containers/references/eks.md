# Amazon Elastic Kubernetes Service

## Overview

Domain expertise for managing Kubernetes clusters using Amazon EKS and deploying workloads to them. Covers various topics.

## When to Load Reference Files

Load the appropriate reference file based on what the user is working on:

- **control plane** -> see [eks-control-plane.md](references/containers/references/eks-control-plane.md)
- **auto mode** -> see [eks-auto-mode.md](references/containers/references/eks-auto-mode.md)
- **cluster compute**, **managing nodes**, **managed node groups**, **fargate**, or **amis** -> see [eks-managing-compute.md](references/containers/references/eks-managing-compute.md)
- **EKS networking**, **VPC CNI**, or **network policies** -> see [eks-networking.md](references/containers/references/eks-networking.md)
- **load balancers**, **ingress**, **gateway API**, or **global accelerator** -> see [eks-load-balancer-controller.md](references/containers/references/eks-load-balancer-controller.md)
- **eks capabilities**, **Argo CD**, **ACK**, or **kro** -> see [eks-capabilities.md](references/containers/references/eks-capabilities.md)
